# Pen for You — Product Overview

## Project Purpose
"Pen for You" (internally also branded as "Inkspired") is a premium pen e-commerce storefront targeting Filipino customers. It allows shoppers to browse, filter, and purchase writing instruments online via a Cash-on-Delivery (COD) checkout flow, backed by a Supabase database.

## Key Features
- Animated hero section with floating product card and canvas background
- Product catalog with category filtering (All, Ballpen, Fountain, Gel, Marker)
- Shopping cart persisted in localStorage
- COD checkout form that saves orders to Supabase
- Real-time order notifications in the admin dashboard via Supabase Realtime
- Admin dashboard (admin.html) with login, product CRUD, order management, and analytics
- Toast notification system for user feedback
- GSAP scroll-triggered animations and 3D card tilt effects
- Responsive mobile menu and layout

## Target Users
- End customers: Filipino pen enthusiasts and everyday writers browsing and buying pens
- Store admin: Shop owner managing products, viewing orders, and tracking sales via the admin dashboard

## Use Cases
- Customer browses the shop, filters by pen type, adds items to cart, and places a COD order
- Admin logs in, adds/edits/deletes products with image uploads to Supabase Storage, and monitors incoming orders in real time

## Pricing & Currency
All prices are displayed in Philippine Peso (PHP).
